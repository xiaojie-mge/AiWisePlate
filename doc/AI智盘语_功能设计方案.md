## 二、左侧面板功能

### ① 策略池
- 显示用户自己的股票列表
- 每条显示：代码、名称、实时涨跌幅
- 点击 → 加载该股票K线图
- 手动添加（输入代码）
- 右键/悬浮菜单：移出策略池、查看详情

### ② 买点信号
- 列表显示近7天触发的买点
- 每条：代码、触发日期、触发价、MA5值
- 点击 → 跳转到对应股票K线
- 新信号有红色闪烁动画

### ③ 断板监控
- 当前处于3日监控窗口内的股票
- 每条：代码、断板日期、剩余监控天数
- 显示当前买点条件是否满足

### ④ 持仓记录
- 用户实际持仓（手动录入）
- 每条：代码、买入价、当前价、浮盈%
- 触发卖点时红色高亮提醒

## 三、K线图功能

### 图表模式
| 模式 | 说明 |
|------|------|
| 实时（分时） | 今日1分钟K线，昨收参考线，买入区间标注 |
| 5日 | 近5个交易日日线，MA5+买点参考线 |

### 图表标注
| 标注 | 样式 | 说明 |
|------|------|------|
| 断板日 | 🔶 橙色图钉 | 前日涨停今日断板 |
| 买点信号 | ↑ 红色箭头 | MA5×1.025触发 |
| 持仓买入 | 💎 蓝色菱形 | 用户实际买入位置 |
| 连板数 | N板角标 | 涨停K线上显示连板数 |
| 监控窗口 | 橙色半透明区间 | 断板后3日监控区 |
| 卖点参考线 | 虚线 | MA5、止盈25%、止损-6% |

## 四、AI 助手功能（右侧面板）

### 与股票联动
- 选中股票后，上下文自动带入当前股票信息
- "AI分析当前"按钮 → 自动发送分析请求
- AI返回内容直接在右侧面板流式显示

### 支持的操作
| 操作 | 示例 |
|------|------|
| 技术分析 | "分析600900当前K线形态" |
| 买卖建议 | "600900现在适合买入吗" |
| 快速回测 | "回测600900近3个月均线策略" |
| 风险评估 | "600900当前主要风险是什么" |
| 自由提问 | 任意问题 |

### 对话持久化
- 同一股票的对话保存在 Session 中
- 切换股票时开新 Session
- 可以查看历史对话

### 定时任务架构

```python
# scheduler.py
scheduler = AsyncIOScheduler()

# 收盘后任务（16:30）
scheduler.add_job(after_market_job, 'cron', 
    day_of_week='mon-fri', hour=16, minute=30)

# 盘中轮询（30秒）
scheduler.add_job(intraday_job, 'interval', seconds=30)

def intraday_job():
    now = datetime.now()
    if not is_market_open(now):
        return
    for user_id in get_active_users():
        check_buy_signals(user_id)
        check_sell_signals(user_id)
        auto_paper_trade(user_id)
```
